Project Description

Pebble Pay lets a street vendor take a payment with a coin. The coin is the token 0.0.2345678 on the test network. The idea is invented for a test.

How it's Made

A small web page asks the buyer to sign. It uses the Hedera Token Service and writes each sale to the topic 0.0.3456789. The version of the page is 0.0.1.
