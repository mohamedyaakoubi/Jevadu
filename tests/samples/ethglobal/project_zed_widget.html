Zed Widget

A widget that records small facts on Hedera.

Project Description

Zed Widget lets a shop keep a public list of small facts. It writes each fact to topic 0.0.1234567 on the test network. The idea is invented for a test.

How it's Made

The widget is a small web page. It uses the Hedera Consensus Service to write each fact. The version of the widget is 0.0.3.
