# Invented sample pages for the ETHGlobal collector

**Every file here is INVENTED. Nothing was taken from a real page.** The names, the projects and the
text are made up, and the people do not exist. The files only give the collector's tests something to
read that has the shape the collector expects.

Why they are invented: no text taken from a collected page may enter git (design rule
18, and design 5.7). A test (`tests/test_promises.py`) checks that every file in this folder starts
with the word INVENTED, so a real page cannot be saved here by mistake.

The shape (a prize page with a list of winners, a project page with a team block and a data block) is
a guess until the maintainer saves a real page by hand. Then the collector's page shape and these files are
changed to match it, still with invented text.
