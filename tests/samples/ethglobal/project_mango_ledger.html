Mango Ledger

Shared notebooks for a fruit stall.

Project Description

Mango Ledger keeps the sales of a fruit stall in a public notebook. The token 0.0.7654329 counts the crates. The idea is invented for a test.

How it's Made

A small server reads the notebook and shows totals. It uses the Hedera Token Service.
