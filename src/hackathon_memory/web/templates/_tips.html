{% call tip("hedera", "Hedera") %}

Hedera{{ parts.ref("hedera") }} is a public network that keeps records nobody can change afterwards: a distributed ledger{{ parts.ref("ledger") }} with its own way of agreeing on the order of events{{ parts.ref("hashgraph") }}. Many hackathons asked teams to build on it. This tool keeps what is still public about their projects.

{% endcall %} {% call tip("idea", "Your idea") %}

Write what your project does, and for whom. One sentence is enough, and a whole description works too, up to {{ "{:,}".format(LONGEST_IDEA) }} characters.

Quick results appear when you stop typing for half a second. Your browser keeps your last search until you clear it. The server keeps no copy of the idea: what Google's models answered about it is kept for one day, under a fingerprint.

{% endcall %} {% call tip("quick", "Quick results") %}

Shown while you type. Gemini has not read them.

  • By meaning: Google's embedding model{{ parts.ref("embedding") }} turns your idea and each project into a long list of numbers. Close numbers mean close ideas, also in other words. It writes nothing.{% if meaning and meaning.known %} In our test it put {{ meaning.found }} of {{ meaning.known }} known similar projects in its first ten.{% endif %}
  • By words: a classic word search (BM25{{ parts.ref("bm25") }}), with no AI at all. Best for a name or an exact term.{% if words and words.known %} In our test: {{ words.found }} of {{ words.known }}.{% endif %}
{% endcall %} {% call tip("ai", "Order and compare with Gemini") %}

Gemini 3.8 Flash{{ parts.ref("gemini") }} reads the 30 projects closest in meaning, puts the ten most similar first, and writes for each of them what is the same as your idea and what differs. It orders and compares. It never scores or judges a project.

{% if by_ai and by_ai.known %}

In our test its order put {{ by_ai.found }} of {{ by_ai.known }} known similar projects in the first ten{% if meaning and meaning.known %}, against {{ meaning.found }} by meaning alone{% endif %}. The order takes about {{ "%.0f" | format(by_ai.seconds) }} s{% if compare_cost %}, the comparisons about {{ "%.0f" | format(compare_cost.seconds) }} s more, and the whole costs about {{ "%.1f" | format(100 * (by_ai.cost_usd + compare_cost.cost_usd)) }} cent{% endif %}.

{% endif %}

Its answers are kept for one day, so the same search does not ask it again.

{% endcall %} {% call tip("orders", "The two orders") %}
  • Quick order: the order of meaning, with no AI that writes.
  • Gemini's order: Gemini puts the ten closest of the 30 closest in meaning first, and compares them with your idea. The first time, it takes a few seconds; after that its answer is kept for one day, so switching back and forth asks Gemini nothing new.
{% endcall %} {% call tip("charts", "Cards or charts") %}

The same list, shown as cards or as charts. The charts count the facts of the projects of the list on the screen: the closest to your idea, or the whole collection with your filters. They are counted now from the tables, never by a model.

{% endcall %} {% call tip("order", "The order") %}

The first is the closest to your idea. The order never says that a project is good, bad, or a copy: the tool shows facts, and people judge.

{% endcall %} {% call tip("event", "Event, prize and winners' list") %}

The hackathon that the project was sent to.

  • Won a Hedera prize: the project took a prize of Hedera at that event.
  • Only in the winners' list: the project's own page is no longer public, so it comes from the organiser's list of winners and has fewer facts. Every project of such a list won a prize, but most winners still have their own page.
{% endcall %} {% call tip("category", "Category") %}

One of 17 themes, chosen by a model (Gemini 3.1 Pro) from the project's page, with the sentences of the page it rests on.{% if all_projects %} {{ with_category }} of {{ "{:,}".format(all_projects) }} projects have one so far.{% endif %}

{% endcall %} {% call tip("proof", "Hedera proof") %}

Does the project show that it really used Hedera? A program looks for Hedera IDs on the page and in the code: an account{{ parts.ref("account") }}, a topic{{ parts.ref("topic") }}, a token{{ parts.ref("token") }} or a smart contract{{ parts.ref("contract") }}. It asks the public mirror node{{ parts.ref("mirror") }} what each one is.

  • Proof found: the ledger knows the ID as that kind of thing, made or used at the time of the event.
  • Dates do not fit: it exists, but from another time.
  • Another kind of ID: the ledger knows the number as something else.
  • ID empty: nothing ever happened with it.
  • ID not found: the ledger does not know it.
  • No ID given: neither the page nor the code names one. This says nothing bad about the project.

Each ID opens on HashScan{{ parts.ref("explorer") }}, where anybody can see the same record.

{% endcall %} {% call tip("life", "Life") %}

Was the project still worked on after the event? A sign of life is a change to its code, or activity of its own Hedera IDs, more than 30 days after the event.

  • Active: a sign in the last 90 days.
  • Quiet: signs, but none in the last 90 days.
  • Stopped: nothing more than 30 days after the event.
  • Too early to tell: the event ended less than 90 days ago.
  • Unknown: no date of the code, and no activity of its IDs.
{% endcall %} {% call tip("ledger", "On the ledger") %}

What the public Hedera ledger{{ parts.ref("ledger") }} says about each ID that the page or the code names, read by a program from a mirror node{{ parts.ref("mirror") }}, with no AI.

The test network{{ parts.ref("testnet") }} and the main network{{ parts.ref("mainnet") }} are separate: the same number is a different thing on each. Each ID opens on HashScan{{ parts.ref("explorer") }}.

{% endcall %} {% call tip("code", "The code") %}

The repository{{ parts.ref("repository") }} that the page links to: when it was made and when it last changed, read from GitHub by a program.

{% endcall %} {% call tip("page", "From the project's page") %}

The team's own words, copied by a program from the project's page as it stood on the day it was saved. No AI changed them.

{% endcall %} {% call tip("model", "Written by a model") %}

Gemini 3.1 Pro read the page and filled these fields. Each field shows a label:

  • Stated: one sentence of the page says it.
  • Inferred: put together from several sentences; read it with more care.
  • Not found: the page says nothing about it.

Under each field are the sentences of the page it rests on. A program checked that each one is really in the page, and a field whose sentences were not found is not shown.

{% endcall %} {% call tip("compare", "Compared with your idea") %}

Written by Gemini 3.8 Flash{{ parts.ref("gemini") }} from the texts named under it: what is the same as your idea, and what differs. It does not judge the project.

{% endcall %} {% call tip("check", "Check a submission") %}

For a judge, or a team before it sends its project. Give the GitHub link of the code and the event.

  • A program asks GitHub's API for the repository and its README: two requests, one after the other, with the name of this tool.
  • It finds the Hedera IDs in the README, asks the public mirror node{{ parts.ref("mirror") }} what each one is, and checks that the dates fit the event.
  • It shows whether the same code or the same ID was already sent to an earlier event, and the closest past projects.

No model writes anything. You can then register the submission on Hedera{{ parts.ref("topic") }}.
