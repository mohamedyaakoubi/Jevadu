Common questions

Why doesn't the AI judge, score or rank the projects?

A verdict needs a basis that can be checked, and here there is none. To trust a model as a judge, people who know the field would first label many examples against written criteria, and the model's answers would be measured against theirs. No such set exists for hackathon projects.

Research on models used as judges also found biases that have nothing to do with quality: preferring the longer answer, or the one shown first{{ parts.ref("mtbench") }}, and, when screening CVs, preferring some names over others{{ parts.ref("cvstudy") }}.

So AI here only does work that can be checked. It summarises a page against written rules and quotes the sentences it used, and code verifies every quote. The facts come from code and from the ledger. People judge.

Where does the data come from?

ETHGlobal was asked before any program read its showcase. It agreed in writing to a slow, rate-limited read of its Hedera prize projects, with the site's name and a contact address in every request, and the other projects that its showcase ties to Hedera are read in exactly the same way. The winners of other events come from the organisers' own public lists.

Hedera data comes from the public mirror node{{ parts.ref("mirror") }}, and code data from GitHub. Every project links to the page it comes from.

Is my idea stored?

Your browser keeps your last search until you clear it. The server does not store your idea. It is sent to Google's models, and their answers are cached for one day under a hash of the idea (a short code computed from it), so the same search is not paid for twice.

Does "no ID given" mean the project did not use Hedera?

No. It means that neither the project page nor the README of its code names an ID that could be checked. Many teams never wrote their IDs down.

Why do some projects have no AI summary?

A summary is made from the project's own page. An entry that comes only from an organiser's list of winners has no page to summarise, so it shows what the list gives.

Why does Gemini only run when I click?

So that you always know when generative AI is used. The default results come from semantic or keyword search. The button calls Gemini, says what it will do, and takes a few seconds.

Why do some events show only their winners?

For those events, the organiser's list of winners is the only part that is still public.
